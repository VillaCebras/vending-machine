----------
name: Coin return request
description: A customer does not complete a purchase and requests money back
----------

# Preconditions

- The vending machine is not under maintenance service.
- No other customer is using the vendor machine.

# Description

1. The system showns the coins returned.
    1.1 The system shows "NO INSERTED COINS" message when the user hasn't added any coin.
2. Clears the total money added by the customer.
3. The customer has released the vending machine.
