----------
name: Add items to be purchased.
description: The maintenance team adds items in the vending machine.
----------

# Preconditions

- The vending machine is under maintenance service.

# Description

1. Maintenance team inserts a list of items from the available (WATER, SODA, JUICE) with its total. Example: WATER-3,JUICE-5,SODA-1.
2. The system updates the item totals.
