----------
name: Add coins to be used as change.
description: The maintenance team adds coins in the vending machine that can be returned to customer.
----------

# Preconditions

- The vending machine is under maintenance service.

# Description

1. Maintenance team inserts a list of coins separated by comma. (Example: 0.05, 0.05, 1, 0.25, 0.10, 0.10)
2. The system updates the total coins available in the machine.
